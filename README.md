# 🐾 Atividade Prática — Landing Page EducaCão

## Desenvolvimento Web com HTML5 e CSS3

**Componente curricular:** Programação Web
**Ferramenta:** Visual Studio Code
**Projeto:** Criação de uma landing page para uma empresa fictícia de adestramento de cães.

## 🎯 Objetivo

Desenvolver uma página web utilizando HTML5 e CSS3, aplicando estrutura semântica, organização de conteúdo, cores, fontes, imagens, layouts com Flexbox e CSS Grid e técnicas de responsividade.

## 🧑‍💼 O desafio do cliente

A EducaCão é uma empresa fictícia de adestramento de cães. O cliente precisa de uma landing page moderna, organizada, acolhedora e adaptável a computadores e celulares.

A página deverá apresentar a empresa, seus serviços, diferenciais, depoimentos e um formulário de contato.

## 🎨 Identidade visual obrigatória

* Verde principal: `#4CAF50`
* Verde-escuro: `#2E7D32`
* Laranja: `#FF9800`
* Fundo creme: `#FFF8E7`
* Branco: `#FFFFFF`
* Fonte dos títulos: Nunito
* Fonte dos textos: Poppins

As cores, fontes e imagens devem seguir a proposta visual definida pelo cliente.

## 🧩 Seções obrigatórias

1. Cabeçalho com logotipo e menu de navegação.
2. Banner principal com título, texto, imagem e botão.
3. Apresentação dos serviços em cartões.
4. Seção sobre a empresa.
5. Diferenciais do atendimento.
6. Depoimentos de clientes fictícios.
7. Formulário de contato.
8. Rodapé.

## 💻 Etapas de desenvolvimento

### Etapa 1 — Preparação

Baixe o projeto, extraia os arquivos e abra a pasta no Visual Studio Code.

### Etapa 2 — HTML

Complete a estrutura da página utilizando tags semânticas, títulos, parágrafos, links, imagens e formulários.

### Etapa 3 — CSS

Implemente as cores, fontes, espaçamentos, botões, cartões, bordas e efeitos visuais.

### Etapa 4 — Layout

Organize os elementos utilizando Flexbox e CSS Grid.

### Etapa 5 — Responsividade

Utilize media queries para adaptar o site a telas menores.

### Etapa 6 — Testes

Confira os links, imagens, ícones, campos do formulário e a apresentação da página em diferentes tamanhos de tela.

## 📋 Regras do projeto

* Respeitar a identidade visual do cliente.
* Manter o código organizado e indentado.
* Utilizar comentários para identificar as seções.
* Evitar erros nos caminhos de arquivos e imagens.
* Testar o resultado no navegador.
* Não copiar uma solução completa sem compreender sua estrutura.

## 📦 Entrega

O projeto deverá conter:

* Arquivo `index.html`.
* Pasta `css` com o arquivo `style.css`.
* Pasta `img`, caso sejam utilizadas imagens locais.
* Todas as seções solicitadas.
* Página funcional e responsiva.

## ⭐ Desafio extra

Personalize os efeitos dos botões, crie uma galeria de imagens e acrescente uma seção original, mantendo a identidade visual da EducaCão.

**Critério principal:** demonstrar que compreendeu como o HTML organiza os conteúdos e como o CSS transforma essa estrutura em uma página web.
