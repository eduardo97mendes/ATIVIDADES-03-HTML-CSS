# Guia de CSS — Atividade Prática Landing Page

Material de apoio para preencher o CSS da atividade no VS Code.

## Como estudar
1. Extraia esta pasta.
2. Abra a pasta no VS Code.
3. Abra os arquivos `.html` no navegador.
4. Cada arquivo explica uma propriedade usada no CSS da atividade.
5. Compare os exemplos e escolha valores adequados para seu projeto.

## Regra básica

```css
propriedade: valor;
```

Exemplo:

```css
color: #ffffff;
```

- `color` = propriedade
- `#ffffff` = valor

### Importante
Não existe um único valor correto para todas as situações. O aluno deve entender o efeito da propriedade e escolher um valor coerente com a landing page.

Também há propriedades que trabalham em conjunto, como:
- `display: flex` + `justify-content` + `align-items` + `gap`
- `display: grid` + `grid-template-columns` + `gap`
- `width` + `max-width`
- `@media` + reorganização do layout em telas menores
