# Guia de Tags HTML — Atividade Prática

Esta pasta contém um arquivo HTML separado para cada tag/elemento estudado na atividade.

## Como usar

1. Extraia esta pasta.
2. Abra a pasta no Visual Studio Code.
3. Abra o arquivo que deseja consultar.
4. Leia a explicação antes de preencher o `index.html`.
5. Use os exemplos como referência, mas crie seus próprios textos relacionados ao tema escolhido.

## Importante

Não altere classes, IDs, caminhos do CSS ou atributos já preparados no `index.html` sem orientação do professor.

O objetivo é entender:

TAG → o que o elemento representa  
ATRIBUTO → qual característica está sendo configurada  
VALOR → qual informação está sendo usada  
CONTEÚDO → o texto ou elemento colocado dentro da tag
