TAG

O que é?
Representa uma opção dentro de um select.

Explicação

Estrutura:
<option value="banho">Banho e Tosa</option>

value = valor interno da opção.
Texto entre as tags = o que o usuário vê.

Exemplos:
value="banho" → Banho e Tosa
value="consulta" → Consulta
value="suporte" → Suporte Técnico
value="orcamento" → Solicitar orçamento

O value deve ser um identificador simples, normalmente sem espaços.
